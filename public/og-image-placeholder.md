# OG Image for Social Sharing

Để tối ưu việc share link lên X (Twitter) và các mạng xã hội khác, bạn cần tạo file `og-image.png` trong thư mục `public/`.

## Yêu cầu:

- **Kích thước**: 1200x630 pixels (tỷ lệ 1.91:1)
- **Format**: PNG hoặc JPG
- **Nội dung**: Logo D2D + text "D2D - Decentralized Deployment" hoặc design tương tự
- **File path**: `/public/og-image.png`

## Công cụ tạo OG Image:

1. **Canva**: https://www.canva.com (template "Social Media Post" 1200x630)
2. **Figma**: Tạo design 1200x630
3. **Online tools**: https://www.opengraph.xyz/

## Lưu ý:

- File sẽ được sử dụng làm preview image khi share link
- Nên có contrast tốt để dễ đọc
- Có thể tạo dynamic OG images bằng API route trong tương lai
